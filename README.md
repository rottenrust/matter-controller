# Свет · Matter Lamp

Локальный пульт для цветной лампы Яндекса **YNDX‑00553**. Команду можно отправить из терминала на Маке. Для управления из Safari в проекте есть экспериментальный веб-интерфейс с палитрой, регулировкой яркости и температуры белого.

| Откуда управлять | Как команда доходит до лампы |
| --- | --- |
| Терминал на Маке | Утилита `chip-tool` обращается к лампе по домашней сети. |
| Safari на Маке или планшете | Локальный сервер на Маке передаёт команду через тот же `chip-tool`. Мак должен бодрствовать. |
| Телефон с собственной привязкой Matter | Телефон общается с лампой самостоятельно. Мак можно выключить. |

**На реальной лампе** контроллер на Маке прочитал состояние питания и открыл окно сопряжения для дополнительного устройства. Панель Safari и дополнительные режимы ещё не прошли сквозную проверку на лампе.

## Первый запрос

Понадобятся Mac, исполняемый `bin/chip-tool` и **собственное** состояние контроллера в `controller-state/`, созданное при сопряжении. В этой конфигурации у лампы адрес узла `1` и номер конечной точки `1`. Если вы начинаете с чистого клона, сначала пройдите [подготовку контроллера и сопряжение](docs/пульт.md#подготовка-контроллера).

Из корня проекта запросите состояние питания. Эта команда оставит свет как есть.

```sh
TMPDIR="$PWD/controller-state" ./bin/chip-tool onoff read on-off 1 1 \
  --storage-directory "$PWD/controller-state"
```

В ответе лампы `OnOff: TRUE` означает, что свет включён, а `OnOff: FALSE` — выключен.

## Пульт в Safari

Палитра задаёт цвет, ползунок белого света охватывает диапазон от 2700 до 6500 К. Для плавного изменения яркости или оттенка можно выбрать время перехода до 10 секунд. В раскрывающемся разделе собраны цветовой цикл, таймер и поведение после восстановления питания.

Для запуска нужны Python 3, домашняя сеть на интерфейсе `en0` и рабочая команда чтения выше. Установщик создаёт личный ярлык и регистрирует фоновую службу для текущего пользователя macOS. Пульт использует HTTP внутри доверенной домашней сети. Ссылка в ярлыке содержит ключ управления. [Установка, ярлык и остановка службы](docs/пульт.md)
