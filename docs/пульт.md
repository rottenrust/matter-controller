# Пульт в Safari

## Подготовка контроллера

Если ваш контроллер уже сопряжён с лампой и использует `controller-state/` в этом проекте, переходите сразу к [проверке связи](../README.md#первый-запрос).

1. Подготовьте среду сборки Connected Home over IP для macOS. Для сопряжения через Bluetooth установите указанный в руководстве Apple профиль и перезагрузите Mac. В каталоге исходников SDK соберите обычный `chip-tool` командой `./scripts/examples/gn_build_example.sh examples/chip-tool out/lamp`. [Среда macOS и профиль](https://github.com/project-chip/connectedhomeip/blob/master/docs/guides/darwin.md#using-chip-tool-on-macos-or-chip-tool-on-ios) · [Сборка chip-tool](https://project-chip.github.io/connectedhomeip-doc/development_controllers/chip-tool/chip_tool_guide.html)
2. В том же окне Terminal сохраните путь командой `MATTER_SDK="$PWD"`, затем перейдите в корень проекта пульта. Следующие команды рассчитаны на стандартную оболочку macOS — zsh. Они создадут закрытый каталог для ключей контроллера и загрузят публичные сертификаты для проверки подлинности серийной лампы. Скрипт загрузки запускайте с Python из подготовленной среды SDK. [Утилита загрузки сертификатов из реестра Matter](https://github.com/project-chip/connectedhomeip/blob/master/credentials/fetch_paa_certs_from_dcl.py)

```zsh
mkdir -p bin
install -m 755 "$MATTER_SDK/out/lamp/chip-tool" bin/chip-tool
mkdir -m 700 -p controller-state
python3 "$MATTER_SDK/credentials/fetch_paa_certs_from_dcl.py" --use-main-net-http --paa-trust-store-path "$PWD/paa"
python3 "$MATTER_SDK/credentials/fetch_paa_certs_from_dcl.py" --use-main-net-http --cd-output-path "$PWD/cd"
```

Если загрузчик сертификатов сообщил `ModuleNotFoundError`, установите его зависимости **в активном виртуальном окружении SDK** командой `python3 -m pip install click click-option-group requests cryptography` и повторите две команды загрузки.

### Сопряжение

Выберите один из двух вариантов. В обоих случаях последняя команда использует те же каталоги ключей и сертификатов. Ввод пароля и кода скрыт.

**Новая лампа.** Включите режим сопряжения по инструкции к лампе. Введите имя домашней сети 2,4 ГГц, её пароль и числовой код Matter с карточки лампы.

```zsh
read -r 'lamp_ssid?Имя сети Wi-Fi: '
read -rs 'lamp_password?Пароль Wi-Fi: '; echo
read -rs 'lamp_code?Код Matter: '; echo
pair_args=(code-wifi 1 "$lamp_ssid" "$lamp_password" "$lamp_code")
```

**Лампа уже работает в другом приложении.** В этом приложении откройте режим сопряжения для другого сервиса и получите новый код. Подключите Mac к той же домашней сети. Для этого варианта достаточно временного кода.

```zsh
read -rs 'lamp_code?Временный код Matter: '; echo
pair_args=(code 1 "$lamp_code")
```

После выбранного варианта выполните в том же окне Terminal:

```zsh
TMPDIR="$PWD/controller-state" ./bin/chip-tool pairing "${pair_args[@]}" \
  --storage-directory "$PWD/controller-state" \
  --paa-trust-store-path "$PWD/paa" --cd-trust-store-path "$PWD/cd"
unset pair_args lamp_ssid lamp_password lamp_code
```

Проверьте результат [запросом состояния лампы](../README.md#первый-запрос) перед установкой веб-пульта. Локально остаются каталоги `bin/`, `paa/`, `cd/`, `controller-state/`, а после установки также `remote-access/` и личный ярлык `.webloc`.

## Установка на Маке

1. Из корня проекта выполните [проверку связи с лампой](../README.md#первый-запрос). Сервер использует те же `bin/chip-tool`, каталог `controller-state/`, узел и конечную точку. Для другой нумерации потребуется адаптировать `remote/server.py`.
2. Проверьте, что `ipconfig getifaddr en0` выводит частный IPv4-адрес домашней сети. Пульт слушает на этом интерфейсе порт 8765. Гостевая сеть с изоляцией устройств может блокировать связь.
3. Запустите `python3 remote/install.py` из пользовательского сеанса macOS. Установщик регистрирует службу в `~/Library/LaunchAgents/` и создаёт в корне проекта личный ярлык **Свет — Гостиная.webloc**. Если macOS запросит разрешение на входящие подключения, разрешите их для доступа с других устройств домашней сети.
4. Откройте ярлык в Safari. Надпись **«На связи»** означает, что пульт смог прочитать состояние лампы. Мак должен бодрствовать, а пользователь, установивший службу, должен оставаться в системе.

## Ярлык на другом устройстве

Передайте ярлык по AirDrop доверенному пользователю Мака или поделитесь открытой страницей из Safari. В Safari на macOS Sonoma или новее выберите **Файл → Добавить в Dock**. На iPad откройте ссылку в Safari и выберите **Поделиться → На экран «Домой»**.

Адрес содержит ключ управления. Любой, кто получил ссылку и имеет доступ к домашней сети, может отправить команду. HTTP передаёт ссылку без шифрования. Используйте пульт в доверенной сети и держите порт 8765 закрытым для входящих соединений из интернета.

## Обслуживание

| Задача | Команда или файл |
| --- | --- |
| Посмотреть состояние службы | `launchctl print gui/$(id -u)/local.matter-lamp.remote` |
| Остановить до следующего входа | `launchctl bootout gui/$(id -u)/local.matter-lamp.remote` |
| Снова запустить | `python3 remote/install.py` |
| Посмотреть ошибки запуска | `remote-access/service-error.log` |

При повторной установке сохраняется ключ из `remote-access/key`. Ключи сопряжения самой лампы хранятся отдельно, в `controller-state/`. Оба каталога и личные ярлыки исключены из публичного набора файлов.
